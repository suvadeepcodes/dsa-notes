**Q**: How can we assign multiple varibles in a single line in Python ? 

**Solution**:

Python allows us to assign multiple variables in a single line ➡️ seperate the variables with a comma and the right hand side varibles  with a a comma as well 

```python
msg1,msg2 = "Hello", "World"
```

**Q**: What is the purpose of the `type()` function ? 

**Solution**:

We can print the type of a variable or value using the `type()` function

```python
print(type(10))
# <class 'int'>
```

**Q**: How can we declare a varible without a value ? 

**Solution**:

```python
my_name = None
```
