# Chap 2 | Variables

## Variable Declaration and Naming Convention

- To declare a variable we use the following syntax

  ```python
  message ="Hello , world!"
  ```

- in python we use snake casing to declare variables

  ```python
  my_name = "Suvadeep"
  ```

## Multiple Assignments

- Python allows us to assign multiple variables in a single line. Just separate the variables with a comma, and the right-hand side values with a comma as well

  ```python
  msg1, msg2 = "Hello", "World"
  ```

## `type()` function

- We can print the type of a variable or value using the `type()` function

  ```python
  print(type(10))
  ```

- This will output: `<class 'int'>`

## Empty Variables

- If we want to declare a variable without a value, we can use the `None` keyword

  ```python
  my_name = None
  ```
